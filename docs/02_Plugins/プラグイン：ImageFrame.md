## お知らせ

このプラグインに移行した時に大多数のImageOnMap地図は移行されたはずなのですが、一部リセットされてしまった地図があります。  
お手数ですが、お気づき次第張り替えをお願いいたします。

<a id="content_3"></a>
## 概要

画像を地図に変換するプラグイン  
TOROServer26.2アップデートの際に[ImageOnMap](../02_Plugins/プラグイン：ImageOnMap.md)の代替として導入された。

<a id="content_4"></a>
## コマンド一覧

詳しくは公式ページを参照

| 構文 | 効果 |
| --- | --- |
| /if create 名前 URL 横幅 高さ | 画像を作成 |
| /if get 名前 | 作った画像を取得 |
| /if list | 作成したマップの一覧を表示 |
