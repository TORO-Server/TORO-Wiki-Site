## TextBeaconとは？

TextBeacon は、Minecraft サーバー向けのプラグインです。  
特定のエリアをプレイヤーが通過したとき、自動でチャットにメッセージを表示させることができます  
看板と**空色のガラス**を使って、誰でも簡単にメッセージゾーンを作れます。

<a id="content_2"></a>
## 必要な権限（パーミッション）

| 権限ノード | 説明 | 対象 |
| --- | --- | --- |
| textbeacon.create | Beaconの設置・看板の取得 | 一般ユーザー |
| textbeacon.use | Beaconゾーンに入ったときメッセージを受け取る | 一般ユーザー |
| textbeacon.remove | 他人のBeaconを削除する | モデレーター以上 |
| textbeacon.admin | 一覧表示・詳細確認・強制削除・可視化 | 管理者 |

<a id="content_3"></a>
## Beaconの設置方法

<a id="content_3_1"></a>
### 方法1：看板を直接設置する

1. まず、地面やブロックに<b>空色のステンドグラス（Light Blue Stained Glass）</b>を、範囲を決めたい形に並べます。
   1. 最大 **5×5×5** の立方体サイズ以内にしてください。
2. 次に、ガラスの**半径5ブロック以内**に看板を設置します。
3. 看板の1行目に以下を入力してください（大文字・小文字どちらでもOK）：

```
[TextBeacon]
```

1. 看板の2〜4行目に表示させたいメッセージを入力します。
   1. 色コードは <b>&1</b> 〜 <b>&f</b> の形式が使えます。
   2. 16進数カラーコード（例: **7ffff**）も使えます。

設置が成功すると、ガラスブロックが消えてBeaconが登録されます。

<a id="content_3_2"></a>
### 方法2：コマンドで看板アイテムを入手して設置する

1. 以下のコマンドを実行します：

```
/tb <表示したいメッセージ>
```

1. 1. **例**： /tb &aエリアへようこそ！\\n&e楽しんでね！
   2. <b>\\\\n</b> を使うと改行できます。
   3. 色コード（<b>&a</b> など）や **rrggbb** 形式のカラーコードが使えます。
2. コマンドを実行するとインベントリに**専用の看板アイテム**が渡されます。
3. その看板を、設置済みの空色のガラスの近くに設置するだけでBeaconが完成します。

<a id="content_4"></a>
## Beaconの削除方法

設置した看板を**素手や道具で破壊**するとBeaconが削除されます。

- **自分で設置した** Beacon は誰でも削除できます。
- **他人の** Beacon を削除するには **textbeacon.remove** 権限が必要です。

<a id="content_5"></a>
## メッセージのON/OFF切り替え

Beaconのメッセージ受信を自分でオフにすることができます。

| コマンド | 説明 |
| --- | --- |
| /tb on | メッセージ受信を<span style="color:green">ON</span>にする |
| /tb off | メッセージ受信を<span style="color:red">OFF</span>にする |

<a id="content_6"></a>
## コマンド一覧（一般ユーザー）

| コマンド | 説明 |
| --- | --- |
| /tb <メッセージ> | メッセージ入り看板アイテムを入手する |
| /tb on | Beaconメッセージの受信をONにする |
| /tb off | Beaconメッセージの受信をOFFにする |

<a id="content_7"></a>
## コマンド一覧（管理者向け）

管理者権限（**textbeacon.admin**）がある場合、以下のコマンドが追加で使えます。

| コマンド | 説明 |
| --- | --- |
| /tb list | 現在のワールドに登録されているBeacon一覧を最寄り10件表示 |
| /tb list owner:<名前> | 指定したプレイヤーが設置したBeaconのみ表示 |
| /tb info \<UUID> | 指定したBeaconの詳細情報を表示 |
| /tb remove \<UUID> | 指定したBeaconを強制削除する |
| /tb show | Beacon範囲をパーティクルで可視化する（トグル） |

<a id="content_8"></a>
## よくある質問（FAQ）

<a id="content_8_3"></a>
### Q. ガラスを置いたのにBeaconが作れません

- 看板からガラスまでが**半径5ブロック以内**になっているか確認してください。
- ガラスが「空色のステンドグラス（Light Blue Stained Glass）」になっているか確認してください。他の色のガラスは使えません。
- ガラスの範囲が**5×5×5**を超えていないか確認してください。
- **textbeacon.create** 権限があるか管理者に確認してください。

<a id="content_8_4"></a>
### Q. ゾーンを通ったのにメッセージが出ません

- <b>/tb off</b> でメッセージをオフにしていないか確認してください。オフにしている場合は <b>/tb on</b> で再度有効にしてください。
- **textbeacon.use** 権限があるか管理者に確認してください。

<a id="content_8_5"></a>
### Q. 設置できるBeaconの大きさに制限はありますか？

はい。ガラスで作るトリガーゾーンは最大**5×5×5**以内（縦横高さそれぞれ5ブロック以内）です。

<a id="content_8_6"></a>
### Q. 看板のメッセージに色を付けるにはどうすればいいですか？

以下の2つの方法で色を付けられます。

- **カラーコード**：&6や &aなど、&と半角英数字で色指定
- **16進カラーコード**：**rrggbb** の形式（例：ff5555 で赤色）

```
/tb &#55ff55ようこそ！\n&e楽しんでね！
```

<a id="content_8_7"></a>
### Q. 看板を設置すると同時にガラスが消えますが、仕様ですか？

はい、仕様です。空色のガラスはプレイヤーの**移動検知ゾーン**として内部的に使われ、登録が完了すると自動的に取り除かれます（見た目には残りませんが機能します）。

**TextBeacon** は [TORO-Server](https://github.com/TORO-Server/TextBeacon) によって開発されたオープンソースプラグインです。
