## 歴史

<a id="content_3_1"></a>
### SalmonServer(2024)

12/24より、鯖主toropon氏が一時的なメンテナンスをするにあたって一時的に開かれた  
当初は2日で終わる想定だったが足りない部品の注文を行ったため想定より長く開かれた  
メンテナンスは難航し、数日間にわたってTOROServerを起動できない状態が続いた。  
当然、その間、暇な鯖民たちは時間を持て余すこととなる。そんな中、2つの避難先が存在した。

<a id="content_3_1_1"></a>
#### サーモンサーバー

Moderator（当時）がtoropon氏の公認のもと、自身のPCでマインクラフトサーバーを開設した。TOROServerの常連ユーザーの多くがこちらで建築を行った。  
また、しゃけ氏による実験的な試みであったこともあり、TOROServerには導入されていない多数のプラグインが導入された。サーバーの復旧に伴い、閉鎖された。

<a id="content_3_1_2"></a>
#### Bloxd.io

マインクラフトを模したゲームで、言葉を選ばず言えばいわゆる無料のパクリゲーである。  
このゲームはDiscordのアクティビティに対応しており、ボイスチャットで頻繁にプレイされた。
