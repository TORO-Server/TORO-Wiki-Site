## 概要

ワールド生成方式は大きなバイオーム。ワールドの大きさは20kmx20km。  
1.19.2、1.19.4、1.20.4で運用され、現在は26.2で運用されている

## 地理

```
ここで扱う地名に、統一された名前はありません。
```

主にスポーン大陸と乾燥大陸の2つの大陸に加えて、北海、鯖東海、鯖南海の3つの海洋が存在する。

<a id="content_3_1"></a>
### スポーン大陸

mainのほとんどの建築が存在する大陸。  
区分にも複数の方法があるが、基本的にスポーン中央/南西方面/北方方面/北東方面/東方方面/南東方面で毛色が異なる。

<a id="content_3_2"></a>
### 乾燥大陸

大陸の気候が全土に渡って砂漠/メサ/サバンナで構成されている過酷な土地。  
その気候もあってか都市開発は未だに局所的である。しかし、鉄道網のみ広域に渡って整備されている。

<a id="content_3_3"></a>
### 海洋/湖

北海〜鯖東海は北海鯖東海連絡運河、鯖東海〜鯖南海は豊海運河で接続されている。  
また、巨大な湖として広足市南方に廣足湖、汐浜北方に見沼の存在する湖、新形市北東に名称のない湖が存在する。
